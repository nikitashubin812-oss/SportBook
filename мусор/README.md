# SportBook - Автоматизированная система бронирования спортивных площадок

Дипломный проект по разработке веб-системы для бронирования спортивных площадок с многоуровневым процессом оплаты, рейтингами и разрешением споров.

## Технологический стек

### Frontend
- **HTML5** - структура страниц
- **CSS3** - стилизация интерфейса
- **JavaScript** - интерактивность и связь с API

### Backend
- **FastAPI** (Python) - REST API сервер
- **SQLAlchemy** - ORM для работы с БД
- **PostgreSQL** - реляционная база данных
- **JWT** - аутентификация пользователей

## Установка и запуск

### 1. Установка PostgreSQL

1. Скачайте и установите [PostgreSQL](https://www.postgresql.org/download/) (версия 14+)
2. Скачайте и установите [pgAdmin 4](https://www.pgadmin.org/download/)

### 2. Создание базы данных

1. Откройте **pgAdmin 4**
2. Создайте новую базу данных:
   - Правый клик на "Databases" → Create → Database
   - Имя: `sportbook`
   - Нажмите "Save"

3. Импортируйте схему:
   - Правый клик на БД `sportbook` → Query Tool
   - Откройте файл `prototype/database_postgresql.sql`
   - Скопируйте весь код и вставьте в Query Tool
   - Нажмите F5 или кнопку Execute

База данных готова! В неё уже загружены тестовые данные.

### 3. Настройка Backend

1. Установите Python 3.10+ с [python.org](https://www.python.org/downloads/)

2. Откройте PowerShell в папке проекта:

```powershell
# Переходим в папку backend
cd backend

# Создаём виртуальное окружение
python -m venv venv

# Активируем виртуальное окружение
.\venv\Scripts\Activate.ps1

# Если возникла ошибка с политикой выполнения, выполните:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# Устанавливаем зависимости
pip install -r requirements.txt
```

3. Создайте файл конфигурации:

```powershell
# Копируем пример конфигурации
copy config.example.env .env

# Открываем в блокноте для редактирования
notepad .env
```

4. В файле `.env` укажите параметры подключения к PostgreSQL:

```env
DATABASE_URL="postgresql://postgres:ваш_пароль@localhost:5432/sportbook"
SECRET_KEY="ваш-секретный-ключ-минимум-32-символа"
ALGORITHM="HS256"
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

Замените `ваш_пароль` на пароль, который вы указали при установке PostgreSQL.

### 4. Запуск Backend

```powershell
# Находясь в папке backend с активированным venv
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Backend запустится на http://localhost:8000

- **API документация:** http://localhost:8000/docs
- **Главная страница:** http://localhost:8000/

## Функционал системы

### Для всех пользователей
- Просмотр каталога площадок с фильтрами
- Просмотр информации о площадке и календаря занятости
- Регистрация и авторизация

### Для арендаторов
- Создание бронирований
- Загрузка чеков об оплате
- Просмотр истории бронирований
- Оценка площадок и арендодателей

### Для арендодателей
- Добавление и управление площадками
- Настройка временных слотов
- Загрузка QR-кодов для оплаты
- Подтверждение/отклонение платежей (24 часа)
- Просмотр бронирований своих площадок

### Для администраторов
- Разрешение спорных ситуаций
- Просмотр всех бронирований и пользователей
- Модерация платформы

## Многоуровневое бронирование

1. **Создание брони** - арендатор выбирает слот
2. **Получение QR-кода** - арендодатель загружает код для оплаты
3. **Предоплата** - арендатор вносит предоплату и загружает чек
4. **Подтверждение** (24 часа):
   - ✅ Подтверждено → бронь активна
   - ❌ Отклонено с чеком → открывается спор
   - ⏱️ Нет чека → бронь аннулируется

## Разработка

### Структура API

```
/                           - Главная страница
/catalog                    - Каталог площадок
/venue/{id}                 - Страница площадки
/cabinet                    - Личный кабинет
/login                      - Вход/регистрация

/api/auth/register          - Регистрация
/api/auth/login             - Вход (получение токена)
/api/auth/me                - Текущий пользователь

/api/venues                 - Список площадок
/api/venues/{id}            - Детали площадки
/api/venues/{id}/time-slots - Временные слоты

/api/bookings               - Создание брони
/api/bookings/my            - Мои бронирования
```

### Запуск в режиме разработки

Backend автоматически перезагружается при изменении кода (флаг `--reload`).

Для работы с фронтендом просто сохраняйте HTML/CSS/JS файлы и обновляйте страницу в браузере.
