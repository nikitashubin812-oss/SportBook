═══════════════════════════════════════════════════════════════
  ИНСТРУКЦИЯ ПО ЗАПУСКУ SportBook
═══════════════════════════════════════════════════════════════

ШАГ 1: Откройте PowerShell
───────────────────────────────────────────────────────────────
1. Нажмите Win + R
2. Введите: powershell
3. Нажмите Enter


ШАГ 2: Перейдите в папку backend
───────────────────────────────────────────────────────────────
Скопируйте и вставьте эту команду:

cd "C:\Users\User\Desktop\Диплом_Шубин\backend"


ШАГ 3: Проверьте файл .env
───────────────────────────────────────────────────────────────
Выполните:

notepad .env

Если файл не открылся, создайте его:

@"
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/sportbook
SECRET_KEY=super-secret-key-for-diploma-sportbook-2025
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
"@ | Out-File -FilePath .env -Encoding utf8

ВАЖНО! В строке DATABASE_URL замените "postgres" (второй) на ваш пароль от PostgreSQL:
DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/sportbook


ШАГ 4: Активируйте виртуальное окружение
───────────────────────────────────────────────────────────────
Выполните:

.\venv\Scripts\Activate.ps1

Если появится ошибка "выполнение сценариев отключено", выполните:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Затем снова:

.\venv\Scripts\Activate.ps1

После активации вы увидите (venv) в начале строки.


ШАГ 5: Установите зависимости
───────────────────────────────────────────────────────────────
Выполните:

pip install -r requirements.txt

Установка займёт 1-2 минуты.


ШАГ 6: Запустите сервер
───────────────────────────────────────────────────────────────
Выполните:

uvicorn main:app --reload --host 0.0.0.0 --port 8000

═══════════════════════════════════════════════════════════════
  ПРОБЛЕМЫ?
═══════════════════════════════════════════════════════════════

1. Ошибка "No module named 'fastapi'":
   → Выполните: pip install -r requirements.txt

2. Ошибка подключения к базе данных:
   → Проверьте, что PostgreSQL запущен
   → Проверьте пароль в файле .env
   → Проверьте, что база sportbook создана в pgAdmin

3. Ошибка "Address already in use":
   → Порт 8000 занят, используйте другой:
     uvicorn main:app --reload --port 8001

4. Страница не открывается:
   → Убедитесь, что сервер запущен (смотрите в консоль)
   → Попробуйте http://127.0.0.1:8000
